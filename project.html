Aim

What this lab achieves

Objective

To understand, generate, and manipulate continuous-time and discrete-time signals — including sinusoidal, exponential, ramp, unit step, and unit impulse signals — and to apply basic signal operations such as amplitude scaling, addition, subtraction, multiplication, time scaling, time reversal, and time shifting.


Learning Outcomes

  • Generate standard continuous and discrete waveforms graphically.
  • Understand the difference between continuous-time and discrete-time representations.
  • Apply amplitude operations: scaling, addition, subtraction, multiplication.
  • Apply time operations: scaling, reversal, delay, and advance.
  • Observe and interpret the resulting waveform changes visually.
  • Evaluate understanding via pretest and post test assessments.

Apparatus

This virtual lab requires only a web browser. No physical setup is needed.

Theory

Signals & Operations — Key Principles

What is a Signal?

A signal is a function of one or more independent variables (typically time) that conveys information about the behaviour of a physical system. Signals can be continuous-time (defined for every instant) or discrete-time (defined only at integer sample points).

x(t) → continuous-time signal
x[n] → discrete-time signal (n ∈ ℤ)

Standard Test Signals

  • Sinusoidal: x(t) = A · sin(2π f t + φ)
  • Exponential: x(t) = A · e^(−a t) (decaying for a > 0)
  • Ramp: x(t) = A · t · u(t)
  • Unit Step: u(t) = 1 for t ≥ 0, 0 otherwise
  • Unit Impulse: δ(t) = 1 at t = 0, 0 elsewhere (idealized)

Basic Operations on Signals

Amplitude Scaling: y(t) = k · x(t)
Addition: y(t) = x₁(t) + x₂(t)
Subtraction: y(t) = x₁(t) − x₂(t)
Multiplication: y(t) = x₁(t) · x₂(t)
Time Scaling: y(t) = x(a·t)
Time Reversal: y(t) = x(−t)
Time Delay: y(t) = x(t − t₀) (t₀ > 0)
Time Advance: y(t) = x(t + t₀) (t₀ > 0)

Key Insight

Amplitude operations affect the vertical axis (y-values) only, while time operations affect the horizontal axis (x-values) only. Time reversal mirrors the signal about the vertical axis; time delay shifts the signal to the right; time advance shifts it to the left.
